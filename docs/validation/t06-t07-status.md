# T06/T07 完整 Mock 操作与数据面板验证

日期：2026-10-23。验证范围为前端 Mock 工作台，图像是合成机器人示意；没有真实日志解析或正式 IsaacSim 视频接入的完成声明。

## 已实现

- 顶栏场景/机器人选择、会话创建与相位、重复创建保护；关闭立即释放本地资源，失败保留待清理会话 ID，可重试后再创建。
- 上传大小和 JSON 映射校验、处理中状态、全部诊断、统计与映射快照；文件先检查再激活，失败的替换上传不会覆盖活动回放或留下旧候选。示例按钮保持一键载入。
- 播放/暂停/停止、0.1x～10x 倍速、前后单步、秒数与原采样帧序号定位、末尾重播。时间轴 100ms 防抖、释放立即提交；预览与已呈现位置分开，等待中的定位合并为最新意图。
- 28 关节分组折叠、有限位进度和颜色、连续关节无限位、夹爪 m 单位、缺失数值“—”及实测/指令/补值/插值/推算来源。底盘位置和 yaw 朝向与图像共同显示。
- ECharts 静态历史曲线，最多 4 通道独立纵轴，缺测断线、超限区间；游标只取已呈现帧，在同一 canvas 中合成。全量历史按日志/通道/时间去重，不随 seek 或重播重复追加。
- 事件倒序、级别过滤、点击定位；明确区分预扫描限位历史与本轮已呈现进度触发的 WS 告警。CPU/内存/GPU/worker 健康按系统时间独立更新。

## 验证

- `npm test`：19 个文件、191 项单元测试通过。
- `npm run build`：TypeScript 检查与生产构建通过。Vite 提示主包 506.61kB（gzip 151.17kB）略高于默认 500kB 建议值；ECharts 按需异步载入，未调整警告阈值来隐藏提示。
- `npm run test:e2e`：14 项真实 Chrome 用例通过。继承同帧像素 ID/CRC、数值文字、进度和运动区域校验；新增上传检查/激活、映射、连续拖动最终位置、原帧定位、实际曲线游标、分组折叠、事件与原生多选交互。
- 健康 Mock 窗口 7.753 秒内 155 次呈现，19.992fps；28 次采样中捕获到采样最大延迟 78.600ms。此时 28 关节和 4 条曲线同时显示。采样包含测试读回开销，不是物理屏幕延迟测量，也不能继承为真实 IsaacSim 性能或长时稳定性验收。

独立审查发现并修复四项问题：多选框状态不一致；失败上传保留旧候选；较旧时间轴定位覆盖新数字定位；关闭失败丢失清理标识。每项均有失败复现及修复后的验证。组折叠测试另修正了错误前提：重新展开需要等待下一帧共同呈现；停止后零时刻本身可能有合成超限事件，不能断言事件必为空。

详细数值和每个用例见 [t06-t07-evidence.json](t06-t07-evidence.json)。截图在 `outputs/t06-t07/workbench.png`，原始浏览器证据在 `output/test-results`。运行产物不纳入源码 Git。测试使用 5183/5184/18010，避开用户已有的 5173 开发服务；不复用或终止用户服务。

## 范围边界

现有契约没有独立通用事件历史端点，因此历史列表仅使用曲线的 `limit_intervals`，页面明确说明。Mock 固定上传上限 1MiB；真实模式前端上限可配置，默认 64MiB，以服务端校验为准。关节折叠、曲线选择在下一次配对呈现时进入画布，故障保持期间不会单独重绘当前数据。真实文件字段、坐标系与单位仍待样例分析；T08 之后继续实现服务端业务，T15 进行正式媒体联调。
