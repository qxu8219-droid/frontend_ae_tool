## 提供的功能

- IsaacSim 6.2.0 / Python 3.12 / PhysX / R1Pro 2026 空场景运动学回放；真实仿真画面与关节、底盘、进度和曲线游标按同帧身份共同呈现。
- CSV/JSON 映射导入与 B041 便携包导入，播放、暂停、停止、倍速、时间/帧定位、单步、限位曲线、阶段标注和历史事件。
- 真实与 Mock 模式分开；单会话生命周期、媒体恢复、worker 故障后新建会话从零加载。
- 本地 `prepare_b041.py` 将 Parquet 和标注转换成 `.b041`；当前网页不直接转换 Parquet 或 MCAP。QC153 的 153 份数据已在本地转换并通过隔离 CPU 导入验证，数据文件不随源码发布。
- 纳秒时钟和质量信息保留。支持经核实的两种排他末端舍入方式；内部边界仍精确匹配，不改写原件时间。

## 版本与验收

后端应用包和前端应用包均为 `1.0.0`。独立的内部协议包仍为 `0.1.0`，wire schema 仍为 1；应用发布不改变协议含义。首版包含后端业务提交 `01d8403` 和前端业务提交 `232634f`，以及发布元数据、规范和自动发布工作流。

本轮发布检查结果见各仓库 `docs/validation/v1.0.0.json`。既有真实 SDK/UI、30 分钟运行和故障测试的历史证据见 [T18](https://github.com/qxu8219-droid/backend_ae_tool/blob/v1.0.0/docs/validation/t18-status.md) 与 [T17](https://github.com/qxu8219-droid/backend_ae_tool/blob/v1.0.0/docs/validation/t17-status.md)；本次发布没有重新运行全部 GPU 长测，也未逐条验收 QC153 的仿真画面。

## 已知边界

- 首版支持已验证的本机 Chrome 环境；Firefox 尚未验收。SDK、USD 资产、媒体工具二进制和有权限的私有日志需按手册另行准备。
- 夹爪映射和离线底盘积分仍带暂定/推算标识，在线无可靠底盘位姿。完整 MCAP、精确实物标定、远程部署/认证、多用户、动力学评测属于后续工作。
- 创建响应尚未返回 sid 就强制关页时，没有服务端租约回收；诊断文件无自动 TTL。T17 单核 CPU <5% 目标尚未达到；性能结果依赖已验证的硬件与非省电档位。
- 2026-11-02 T18 归档的 npm audit 为 5 个受影响包，其中 2 个 critical 开发依赖；生产依赖为 2 个 moderate。现有配置未启用其中部分触发路径，Tinypool 前置污染链尚未排除。本版本是本地功能交付，不表示依赖安全验收或公开部署完成；具体适用范围见 T18 记录。

## 后续开发

`main` 为集成主线，`v1.0.0` 为不可移动的首版基线。每项功能/修复从最新 `main` 新建短期分支，经过测试和 PR 审查再合并；跨仓库变更须保持契约和配对版本一致。详见各仓库 `CONTRIBUTING.md`。原有 `t18-local-20261102` 保持历史含义，不改写其位置或当时的验收结论。
