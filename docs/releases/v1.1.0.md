## 本次变化

- 浅色工作台采用顶部工具条，左右臂及夹爪并排、躯干和底盘并排；四条历史曲线下方集中展示阶段、限位与运行记录。
- 日志导入、当前日志详情、映射快照与阶段来源使用抽屉；通道选择、精确定位、关闭会话确认和健康信息使用局部弹层。
- 日志详情按会话和日志身份保留。上传候选日志不会覆盖正在回放日志的详情；详情缓存缺失时明确提示。
- 增加可展开的当前呈现数据表，提供完整的 28 个关节名称、值、单位、来源与限位信息；与画面使用同一个已呈现快照。
- 修复数值秒数/帧序号定位时的输入类型问题，补齐键盘导航、定位状态、候选保留和测试目录监听处理。

## 兼容性

本次后端仅调整应用版本与发布文档，业务代码、数据转换和仿真逻辑不变；REST/WS/IPC 契约、生成接口文件及依赖版本均未改变。内部协议包仍为 `0.1.0`，wire schema 仍为 1；API 文档中的既有接口版本不随本次应用版本调整。

继续使用 IsaacSim 6.2.0、Python 3.12 和 R1Pro 2026 资产。画面、关节、底盘、时间/进度与曲线游标保持同帧呈现；红绿采集标识仍用于帧身份校验。worker 故障后仍须关闭、新建会话并重新上传日志。

## 验证范围

发布回归的命令、结果和本地日志摘要见各仓库 `docs/validation/v1.1.0.json`。浅色界面的代码审查与真实 SDK/UI 证据见 [工作台验证记录](https://github.com/qxu8219-droid/frontend_ae_tool/blob/v1.1.0/docs/validation/light-workbench-status.md) 和 [机器可读记录](https://github.com/qxu8219-droid/frontend_ae_tool/blob/v1.1.0/docs/validation/light-workbench-evidence.json)。

真实 SDK/UI 已在前端业务提交 `38843f9`、后端业务基线 `e740103` 上通过：合成日志 65 个独立配对样本，健康采样约 19.75fps、最大共同延迟约 156.7ms；B041 离线与在线样本 32 个配对检查点，页面错误为零。发布准备仅更新版本元数据和文档，未再次运行 GPU 测试。没有重新执行 30 分钟长测、Firefox 验收或全部 153 份日志的 GPU 回放。

## 已知边界

- 继续以已验证的本机 Chrome 环境为准；Firefox、移动端、远程部署和多用户未验收。源码发布不部署或重启正在运行的服务。
- 夹爪映射和离线底盘积分仍带暂定/推算标记，在线无可靠底盘位姿；网页仍需上传预先转换的 `.b041`，不能直接导入 Parquet/MCAP。
- Vite 主包仍超过 500kB 的构建警告阈值；本次未更新依赖，首版记录的依赖安全与其他运行边界仍适用，参见 [v1.0.0](https://github.com/qxu8219-droid/backend_ae_tool/blob/v1.0.0/docs/releases/v1.0.0.md)。
- 私有真机日志、USD 资产、环境、录像与原始测试输出不随源码发布。
